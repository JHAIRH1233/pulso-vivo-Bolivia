# Presentación de Rimay

Guion sugerido para una presentación de cinco diapositivas. No usar métricas de impacto hasta contar con mediciones de una prueba real.

## 1. La información pública debe poder entenderse

- Los comunicados pueden dejar dudas sobre fechas, lugares, horarios o requisitos.
- Una misma información puede necesitar distintos formatos e idiomas.
- **Idea clave:** comunicar no es solo publicar; también es facilitar la comprensión.

## 2. Qué propone Rimay

- Revisar comunicados para detectar información que podría faltar o ser ambigua.
- Ofrecer respuestas basadas en el contenido publicado.
- Acercar el contenido en español claro y en quechua, con validación comunitaria.

## 3. Cómo funciona el flujo

1. La institución prepara un comunicado.
2. Las herramientas de IA ayudan a revisar y transformar el texto.
3. La comunidad consulta la información y pregunta lo que no queda claro.
4. La institución conserva la decisión editorial sobre cualquier aclaración.

## 4. Qué podemos mostrar hoy

- Web pública de demostración con comunicados de ejemplo.
- API para Gap Detector, asistente, traducción al quechua y generación de audio.
- Las funciones web institucionales, el radar y las aclaraciones siguen pendientes de integración en `main`.

## 5. Qué falta validar

- Revisar traducciones y vocabulario con hablantes de quechua de las comunidades objetivo.
- Evaluar la pronunciación del proveedor de voz antes de usarla públicamente.
- Completar el ciclo institucional de revisión, publicación y almacenamiento.
- Probar usabilidad y comprensión con ciudadanía e instituciones.
